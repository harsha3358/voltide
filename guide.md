# Handbook: how VOLTIDE works

> TL;DR: watch the story, do the missions, collect XP, decrypt LAGZILLA's secret message, beat the boss. Learn cloud computing by accident.

## For students

1. Start with **Episode 01 · SPARK**. The others unlock when your facilitator drops the code in class.
2. Every mission (topic) follows the same rhythm:
   - **Volty's hook**: why you should care, in one line.
   - **TL;DR**: the idea in one sentence.
   - **⚡ / 🌊 Analogy**: a picture your brain already understands.
   - **Jargon, translated**: new words, defined like a human would.
   - **Live demo**: try it in the browser. No cloud bill, ever.
   - **Hands-on lab**: commands for *your own* Ubuntu VM, with the expected output shown.
   - **Checkpoint**: one question, **+50 XP**. Three right in a row starts a combo for double XP.
3. Press **Mark mission complete** (+30 XP). That also cracks one fragment of LAGZILLA's **secret transmission**.
4. At the end of each episode: the **boss fight**. 20 seconds per question, 3 lives, +400 XP and a badge.
5. Your **profile** (click the XP bar) has your handle, badges, rank ladder and certificate.
6. Stuck on a word? Use the [jargon buster](#/glossary).

## Buttons you'll see

| Button | What it does |
|---|---|
| XP bar (top) | Opens your profile |
| 🔍 | Glossary / jargon buster |
| 📖 | This handbook |
| 🔈 | Sound effects on/off (off by default) |
| ⚡ | Full effects ↔ lite mode (for older lab PCs) |
| ↑ (bottom-left) | Back to top |
| Copy mission link | Share a mission with your squad |

Any link marked **↗** opens the real website (VirtualBox, AWS Console, Google App Engine…) in a new tab.

## The golden rule of the cloud

> Use the **free tier**, set a **billing alert**, and **stop or delete** every cloud resource when you're done. Stop what you start.

See [cloud account safety](#/session/1/topic/cloud-account).
