# Session 01 · SPARK: Foundations from Zero 🔓

> From bits and pipes to passwords: the first current of cybersecurity.

**Open in the app:** `#/session/1` · **Field guide:** [`guide.md`](guide.md) (or `#/session/1/guide`)

## Who it is for
Students who have never studied computing or security. No prior knowledge assumed.

## By the end, students can
- Explain how data is stored as bits and moves across the internet as packets
- Describe IaaS, PaaS and SaaS, and what *you* must secure in each
- Describe the CIA triad and tell a threat, a vulnerability and a risk apart
- Recognise common malware and spot a phishing message
- Explain why websites store password hashes, and how MFA protects accounts
- Say where ethical hacking ends and crime begins under Indian law
- Run two virtual machines on an isolated network and use basic Linux commands
