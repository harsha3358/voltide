# Episode 02 · CURRENT: Computer Networks 🔒

> Your DMs travel through more boxes than a Flipkart parcel. Time to find out which ones.
> *(Cloud Computing Workshop · Day 1 · Session 02: Computer Networks)*

**Open in the app:** `#/session/2` · **Field guide:** [`guide.md`](guide.md) (or `#/session/2/guide`)

Locked until the facilitator shares the code (see [`facilitator/README.md`](../../facilitator/README.md)).

## By the end, students can
- Tell public and private IP addresses apart
- Explain DNS, HTTP and HTTPS, and read common status codes
- Explain TCP vs UDP and what a port is
- Explain routers, default gateways and NAT
- Configure firewall rules (ufw) and cloud security groups safely
- Use `ping`, `ip addr` / `ipconfig`, `nslookup`, `curl` and `traceroute`
- Explain how a browser reaches a cloud server, step by step
